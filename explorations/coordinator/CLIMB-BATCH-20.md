# Climb batch 20

## 1. For the curator

### The words this record uses

- **Walk** is the interpreter. It runs a program without static types. The **compiled path** checks a program's types with the **checker**, then makes JVM bytecode.
- **The one library** is the interpreter's library (`Library/`, `ProjectFortress/LibraryBuiltin/`). At the **switch-over** the compiled path takes it over.
- **The distance** is the number of errors the checker reports on the one library. Each error has a **site** (a file and a line). **The count** is the checker's errors on the library's `FortressLibrary` component, read by the **count stage**, which also gives the checker's time.
- An **api** is a component's interface (a `.fsi` file); the **component** is its code (a `.fss` file). An **export error** is one error of the checker that lists every declaration where an api and its component differ; each declaration it lists is an **entry**. `FortressLibrary` has two export errors: the **first** lists declarations of the api that the component lacks, the **second** traits and objects whose api and component differ.
- An **unused size** is a size parameter that occurs in no parameter type, return type or body (F-35). **Decision E's diff** (E3) removes the unused sizes of 17 vector and matrix operators from the api; you took it this morning (P-40).
- **Contract E** is your answer for an integer raised to a negative power (P-153): the integer's own type at every exponent, `IntegerOverflow` where the result is no integer, `DivisionByZero` at a base of 0, bases 1 and -1 exact.
- A **row** is an entry of the gap ledger, cited by number. An **item** is a numbered question in PLAN's list "Pavol's answers".
- A **rung** is one fix, built by one worker in its own copy of the tree and checked by a second worker, the skeptic. A **batch** is a few rungs, merged and tested together by the **gate** and landed at once. **The gather** lands the approved rungs on `main`; a new row is written `NEW-I-1` and the like until the gather numbers it.
- **Test first.** Every fix starts with a test that shows the defect, seen failing before the edit and passing after. An **expected failure** is a test named `XXX...` that passes while the defect is there; when the fix lands it is **promoted** to a plain name. A **guard** is a test that passes before and after: it asserts what the change must keep.
- **`cast`** is the library's own function that checks a value's run-time type and gives it a narrower static type (`Library/FortressLibrary.fss:33-37`).
