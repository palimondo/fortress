## Revival change

Revival change: none. The change brings the compiled path to what the specification says and walk does: a value of an intersection is a value of each conjunct (`Specification/basic/types-vals-vars.tex:627-628`), a dotted call binds the receiver to the method's `self` (`Specification/basic/expressions/method-invocation.tex:47-48`), and walk runs the value's own method. The team's code generator narrowed an intersection receiver only where its conjuncts nest and crashed otherwise (`CodeGen.java:7420-7450`, `:7323` on the base), a failure that no source states as the language's behaviour; no rule of the language changes.
