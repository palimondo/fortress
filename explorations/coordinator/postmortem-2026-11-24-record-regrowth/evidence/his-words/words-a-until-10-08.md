## Script and count

The script that selected his messages (run as `python3 -I sel.py <parts folder> <output file>`): it walks the part files in name order and keeps each line of type `user` whose message content is a plain string, or whose list holds a `text` item and no `tool_result`, and whose text does not start with `<`.

```python
import json,glob,sys
d=sys.argv[1]
n=0
out=open(sys.argv[2],'w')
for f in sorted(glob.glob(d+'/*.jsonl')):
    for line in open(f,encoding='utf-8',errors='replace'):
        try: o=json.loads(line)
        except Exception: continue
        if o.get('type')!='user': continue
        c=o.get('message',{}).get('content')
        t=None
        if isinstance(c,str): t=c
        elif isinstance(c,list):
            if any(isinstance(i,dict) and i.get('type')=='tool_result' for i in c): continue
            for i in c:
                if isinstance(i,dict) and i.get('type')=='text':
                    t=i.get('text'); break
        if t is None or t.lstrip().startswith('<'): continue
        n+=1
        out.write('=== %s [%s]\n%s\n\n'%(o.get('timestamp'),n,t))
print(n)
```
