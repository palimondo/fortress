# v1: the first APL sub-language

`base/`, `rung-1/`, `rung-2/` and `rung-2b/` here ran against the **first** APL
library, whose carrier was one `value object AplArr(shape, data)` with the rank
as run-time data and every primitive a string dispatch (`aplDy`, `aplMon`).

They are kept as the record: their reports, probes and outputs are what the
native-carrier design in `../base/` was priced against (`../rung-1/REPORT.md`),
and their gap rows 1-35 in `../gaps.md` were all earned here.

(The run recipes inside these files name `explorations/apl/base` on the source
path; read that as `explorations/apl/v1/base` now.)
