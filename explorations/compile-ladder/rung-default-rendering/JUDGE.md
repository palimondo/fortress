## 3. The repair's shape: a decision, with the alternatives

The rule the repaired default must implement is: **a value whose class renders itself in Java keeps that rendering; every other value renders as its Fortress type name.** That is the old default's good half (`stringOps.java:42-45`, DRC's `a.toString()`) with the cycle removed, and it restores `CLIMB-BATCH-3.md:134` on every class: for a class with its own `toString`, `asString` and `toString` are both that method; for a generated class, `toString` is `this.asString().toString()` (`FValue.java:25-27`) and `asString` is the type name.

**Decided: detect "renders itself in Java" by the declaring class of `toString`, and keep `typeName` as it is.** A new public static `defaultAsString(Any)` in `stringOps.java` answers `a.toString()` when `a.getClass().getMethod("toString").getDeclaringClass()` is neither `FValue.class` nor `java.lang.Object.class`, and `typeName(a)` otherwise; `CompilerBuiltin.fss:351` binds `defaultAsString`, not `typeName`. It is safe because codegen emits no `toString` of its own — `grep -rn '"toString"' compiler/codegen/ runtimeSystem/` finds only the `StringBuilder` call at `CodeGen.java:2108` — so every generated class resolves `toString` to `FValue`'s (`CLIMB-BATCH-3.md:130`, `FValue.java:25-27`), and every class in `compiler/runtimeValues/` overrides it (all 18, `FVoid` included). The `Object.class` guard keeps the identity-hash rendering Pavol rejected (`CLIMB-BATCH-3.md:126`) out for any `Any` that does not descend from `FValue`; none exists today. Reflection on a rendering path costs nothing that matters. The alternatives, rejected:

- *A package test* (`getClass().getName()` under `com.sun.fortress.compiler.runtimeValues.`): one line and no reflection, but it carries a hidden precondition, that every class in that package overrides `toString`, and a future class there without one would close the cycle again. The declaring-class test is the rule itself and has no precondition.
- *Two getters in `CompilerBuiltin`*: the right long-term shape and ruled out for this batch by `CLIMB-BATCH-3.md:164`; it also needs two natives of its own (`FStringVector`'s `asSring` is unusable as it stands). Recorded for the switch-over in the row-321 note.
- *Fold the fallback into `typeName` and rename it*: one public method fewer, but the pure type-name function is what row 354's repair (`getter ilkName(): String = jTypeName(self)`, record.md:19) is written against, and a function that does two things earns a name that says neither. Two functions, each doing one thing, is the honest shape. The manifest's "one new native behind the compiled `Object.asString` default" is met: one native is bound, `defaultAsString`; `typeName` is a public static it calls and that the row-354 rung will import.

The worker's decision to keep `stringOps.asString` and its `jAsString` import stands as a recorded decision; it is not a defect and the repair does not touch it.
