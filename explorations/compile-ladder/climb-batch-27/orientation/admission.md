# Climb batch 27: orientation admission

Seven entries are admitted. They make three edits:

1. **`Number` declares nothing (P-165, P-160, F-324).** This is a new rule in "Numbers". It adds one sentence to the Meet Rule paragraph in "Dispatch and overloading".
2. **Where a type declares no `=`, `=` is `SEQV`, and strings are reference objects (P-168, F-326).** This is a new rule in "Traits and objects", beside the rule on pairs and triples.
3. **Walk prints its numeral classes by the traits' names (F-328, P-167).** This adds one clause to an existing sentence in "Numbers".

Each of the three corrects a default that pretraining, the team's code or the orientation's own text gives a worker. For the first two, a test that a worker wrote is on record failing under the new rule. The third has weaker evidence: it is admitted as a qualification of a sentence, not as a rule. No other entry changes what a worker brings to a task, or an area part owns it. Several area parts now hold false sentences, listed under "Elsewhere" below.
