5. The model

microgpt follows GPT-2 with three simplifications: RMSNorm instead of LayerNorm, no biases, ReLU instead of GeLU. Its gpt function processes one token at a time and keeps the keys and values of earlier positions in a cache. This article's primary form processes the whole sequence at once, which is how the papers write it; section 5.6 shows the one-token-at-a-time form, which is verified too.

5.1 RMSNorm

def rmsnorm(x):
    ms = sum(xi * xi for xi in x) / len(x)
    scale = (ms + 1e-5) ** -0.5
    return [xi * scale for xi in x]

The mean square is a ∑ over the elements of x divided by |x|; scale x is scalar–vector juxtaposition. The −0.5 power is the same node the Python builds (** -0.5).

5.2 Softmax

def softmax(logits):
    max_val = max(val.data for val in logits)
    exps = [(val - max_val).exp() for val in logits]
    total = sum(exps)
    return [e / total for e in exps]

BIG MAX is the library's maximum big operator over plain numbers (the shift m is a constant, not part of the graph, in both programs). Subtracting m before exponentiating is the standard overflow guard and does not change the result.

5.3 Attention

For each layer, every position's vector is projected to a query, a key and a value; a position attends to all positions up to itself: its query is scored against those keys, the scores become weights through softmax, and the weights mix the corresponding values. The reference does this one token at a time (the cached keys and values are the earlier positions'):

q = linear(x, state_dict[f'layer{li}.attn_wq'])
k = linear(x, state_dict[f'layer{li}.attn_wk'])
v = linear(x, state_dict[f'layer{li}.attn_wv'])
keys[li].append(k)
values[li].append(v)
x_attn = []
for h in range(n_head):
    hs = h * head_dim
    q_h = q[hs:hs+head_dim]
    k_h = [ki[hs:hs+head_dim] for ki in keys[li]]
    v_h = [vi[hs:hs+head_dim] for vi in values[li]]
    attn_logits = [sum(q_h[j] * k_h[t][j] for j in range(head_dim)) / head_dim**0.5 for t in range(len(k_h))]
    attn_weights = softmax(attn_logits)
    head_out = [sum(attn_weights[t] * v_h[t][j] for t in range(len(v_h))) for j in range(head_dim)]
    x_attn.extend(head_out)
x = linear(x_attn, state_dict[f'layer{li}.attn_wo'])

Written for the whole sequence X (one row per position) and one head h of width dh:

The Fortress layer is that formula. Q, K, V are matrices whose rows are W_q x, W_k x, W_v x for each position; .cols(c) restricts them to head h's columns; for position t, Kh[0:t] Qh[t] is the vector of scores against the keys of positions 0…t, and alpha Vh[0:t] is the row-vector–matrix product that mixes the values. The heads are concatenated with the BIG || operator and projected by W_o. Because every position is computed by a comprehension over X.indices, positions are independent iterations — in Fortress that means they may run in parallel; the reference's token loop is inherently sequential.

The two remaining lines of the block are the MLP and the residual stream:

x_residual = x
x = rmsnorm(x)
x = linear(x, state_dict[f'layer{li}.mlp_fc1'])
x = [xi.relu() for xi in x]
x = linear(x, state_dict[f'layer{li}.mlp_fc2'])
x = [a + b for a, b in zip(x, x_residual)]

mlp(x: Vec): Vec = W_out relu(W_in x) is the first formula; forward is the second, with X' as the primed intermediate. (Two small elementwise helpers at the top of the figure lift + and rmsnorm to a whole sequence; matrices() lists the layer's parameters for the optimizer.)

5.4 Embeddings, layers, logits

tok_emb = state_dict['wte'][token_id] # token embedding
pos_emb = state_dict['wpe'][pos_id] # position embedding
x = [t + p for t, p in zip(tok_emb, pos_emb)] # joint token and position embedding
x = rmsnorm(x)
for li in range(n_layer):
    ...
logits = linear(x, state_dict['lm_head'])

The token embedding table E and the position table P are matrices whose rows are looked up by subscript; the input at position t is rmsnorm(E[tokens[t]] + P[t]). Layers are applied in order (the only genuinely sequential loop in the forward pass), and W_lm x maps each final vector to one logit per vocabulary entry. params() flattens every matrix into the single parameter list the optimizer walks.

5.5 Parameters

The reference initializes each matrix with Gaussian noise of standard deviation 0.08 and keeps them in a dictionary; in Fortress the matrices are constructor arguments of Layer and Model, built from lists of numbers by Mat(⟨ Vec(⟨ node(x) | x ← row ⟩) | row ← rows ⟩). For the verification run the numbers are the reference's own initial weights (dumped from the seeded Python run); the demo in section 6 starts from the same weights. Fortress's library has no Gaussian generator, so a uniform-based initializer is used only in the smoke test.

matrix = lambda nout, nin, std=0.08: [[Value(random.gauss(0, std)) for _ in range(nin)] for _ in range(nout)]
state_dict = {'wte': matrix(vocab_size, n_embd), 'wpe': matrix(block_size, n_embd), 'lm_head': matrix(vocab_size, n_embd)}
