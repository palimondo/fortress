39.1 Convenience Functions

39.1.1 tuple⟦T extends Tuple⟧(x: T): T

The function tuple returns its argument as a tuple expression.

39.1.2 coerce⟦T⟧(x: T): T

The function coerce returns its argument as the given type.

39.2 Convenience Types

An optional value v of type Maybe⟦T⟧ is either Nothing⟦T⟧ or Just(v) declared as follows:

(* Optional Values *)
trait Maybe[\T\] comprises { Nothing[\T\], Just[\T\] }
  isNothing: Boolean
end
value object Nothing[\T\] extends Maybe[\T\]
end
object Just[\T\](just: T) extends Maybe[\T\]
end

The empty case is one object for each type T, and each use writes the type, as in Nothing⟦String⟧. The following declaration of a single Nothing for every instantiation of Maybe is not allowed:

(* Not allowed! *)
object Nothing extends Maybe[\T\] excludes Just[\T\] where {T extends Object}
end

It would make Nothing a Maybe⟦T⟧ for every T at once, which instantiation exclusion forbids (Section 12.6); and an object declaration has no excludes clause (Section 11.1), an object trait type already excluding every type that is not its supertype (Section 6.3.1).

Revised by the 2026 revival see Section I.1.7

The Working Draft of February 2011 declared Nothing with the declaration marked “Not allowed”. The declaration of Nothing⟦T⟧ is the library’s, whose own source says it “will become a non-parametric singleton when we get where clauses working”; instantiation exclusion closes that road.
