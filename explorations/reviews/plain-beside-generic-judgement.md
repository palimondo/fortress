# A generic declaration beside a plain one: the judgement

The question is PLAN item 30 (row 496). Answer 9 lets a name have a generic declaration and a plain one. When the checker sends a call to the plain one and the value at run time also fits the generic one, which declaration runs, and at which instance? The clean worker's list (`reviews/plain-beside-generic-ways.md`, "the list" below) gives five ways with their measurements. This note checks its deciding claims against their sources, weighs the ways, and recommends one.

## 1. The question, in plain words

Terms first.

- A *declaration* (an "arm") is one definition of a name. A *generic* declaration has static parameters, `grab[\X\](t: Tag[\X\])`; a *plain* one has none, `grab(a: Any)`.
- The *static choice* is the declaration the checker picks from the declared types. *Dispatch* is the choice made at run time from the values' actual types: Fortress runs the most specific declaration that fits the values. Java does not do this; Julia does.
- An *instance* of a generic declaration is the declaration at one value of its parameters, `grab` at `X = Red`. On the compiled path each instance is a class stamped from a template.

The shape. `grab[\X\](t: Tag[\X\]): Marker[\X\]` beside `grab(a: Any): Any`, and a call `grab(a)` where `a` is declared `Any` and holds a `RedTag`, which is a `Tag[\Red\]`. The checker picks the plain declaration, the only one whose declared domain holds `Any`. At run time the generic one fits too, and it is narrower. Two things are asked: which declaration runs, and if the generic one, what `X` is.

Why the question exists. Fortress keeps generics at run time (the instantiating loader, type descriptors, sizes as descriptors since batch 5) and dispatches on the run-time types of all arguments. A language that erases generics and resolves overloads statically cannot ask this; both design choices are the team's.

## For Pavol

**Question.** When a name has a generic declaration and a plain one, and a call the checker sent to the plain one carries a value that fits the generic one, which runs, and at which type?

**Context.**

- Refresher. There are two choices. The checker chooses from declared types (the static choice). At run time Fortress chooses again from the values' actual types and runs the narrowest declaration that fits, on all arguments; Java never does this, Julia always does. A generic declaration is a family: `grab[\X\](t: Tag[\X\])` fits every `Tag`, and the value says which `X`.
- The shape. `grab[\X\](t: Tag[\X\])` beside `grab(a: Any)`, called `grab(a)` with `a` declared `Any` and holding a `RedTag`. The checker picks the plain one, the only one that takes `Any`. At run time the generic one fits too and is narrower.
- What the designers said. The 2011 paper names this exact case and says the generic declaration runs, its parameter inferred at run time. Their 2012 calculus, their restart of the specification and Naden's 2012 notes say the same. Nobody wrote the other answer; its only support is the 2009 sentence your answer 9 removes.
- What the paths do. Both were built for the generic answer. The compiled path gives it in the team's own gated test and in seven of ours; rung G's two programs crash on two code-generation slips (a `ZZ32` spelled two ways; a cast to the wrong class), not because the plain one was chosen. Walk gives the generic answer; its one "plain" answer is a 2007 bug, row 157: it cannot instantiate a generic declaration declared to return `Any` and drops it silently.
- What the library does. Every list and map comprehension joins its pieces through exactly this shape (`APPCOV`, whose plain declaration is a deliberate `fail`), and the pair `=` sits beside the `Any` `=`. The plain answer breaks both.
- Your decision of this morning (conversions and overloading, decision 1) already says which declaration: dispatch goes "to the most specific declaration applicable to the values", and a generic one fits "when some instance within its bounds fits". What it leaves unwritten is which instance a declaration reached only at run time gets. One sentence.
- microGPT has no such pair.
- Speed. A call written at the exact type compiles to a direct call of the stamped instance, with no dispatch. Only a call through a wider type pays one test and one lookup. The generic declaration at the value's type is the specialised copy; the plain one over `Any` is the catch-all.
