  Reading: the second implicit thread sees the aborted block's write too.  That does NOT
  refute row 324's account, because a child task inherits its parent's transaction --
  `BaseTask(BaseTask parent) { ... this.transaction = parent.transaction; }`,
  runtimeSystem/BaseTask.java:83-86 -- so the inherited orphan is exactly what the child
