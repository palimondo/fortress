10. Reproducing everything

All files live under experiment/worker/ of the repository; the interpreter is the historical Fortress tree, unmodified.

source experiment/env.sh                                   # Java 25, single-thread interpreter
experiment/worker/run.sh experiment/worker/src/MicroGPT.fss # smoke test with random weights (~35 s)
python3 experiment/worker/tools/derive_checks.py 2 3         # needs reference/microgpt.py + input.txt (not committed)
python3 experiment/worker/tools/gen_data.py                  # -> src/MicroGPTData.{fsi,fss} (committed)
python3 experiment/worker/tools/build.py                     # -> build/Check.fss
cp experiment/worker/src/MicroGPTData.* experiment/worker/build/
experiment/worker/run.sh experiment/worker/build/Check.fss  # 52 checks, ~2 min
python3 experiment/worker/tools/build.py experiment/worker/src/MicroGPT.fss train_main.part Train
experiment/worker/run.sh experiment/worker/build/Train.fss  # bounded training demo, ~15 min
python3 experiment/worker/tools/figs.py experiment/worker/src/MicroGPT.fss gpt   # typeset the figures
python3 experiment/worker/tools/build_article.py            # this page
  • notes/01-orientation.md — the checkout survey and every probe's finding with evidence; notes/02-v1-verified.md, notes/03-design.md, notes/gaps.md — milestone notes (attempt, observation, decision, uncertainty) and the classified gap list.
  • probes/ — 39 small runnable programs, failures included; transcript.txt — every interpreter and typesetting invocation with its output.
  • checks/checks_2steps.json — the reference-derived data; checks/check_run_v{1,2,3}_output.txt, checks/train_demo_output.txt — run outputs.
  • figures/*.tic, *.svg — figure sources and renderings; article/sections/*.html and article/math_table.py — this article's sources.

The reference Python and dataset are not committed (their licenses are unstated); they are fetched from the pinned URLs by the commands in notes/01-orientation.md. Fortress and Fortify are Sun Microsystems / Oracle work under their own license in the repository root.
