## 1. The shadow

`P5/make-shadow.py` copies `ProjectFortress/src/com/sun/fortress/compiler/desugarer/PreDisambiguationDesugaringVisitor.java`. With `-Dprobe.p5=true`, its `forStaticParam` (`:134-148`) leaves a static parameter's `extends` clause as written. That switches off the compile path's `extends Object` pre-desugaring for static parameters. The rewrite does nothing else: its second use, `extends Object` on a trait or object with no `extends` clause, stays on. Without the switch the copy behaves as the tracked file. It is one line (`P5/shadow.patch`), compiled with `javac` against the private home's frozen classpath and put first on it (`P5/build.sh`).

This is the switch the record names (row 412; `explorations/coordinator/two-libraries.md`, "A difference that is not in the library files"). The distance triage's earlier shadow wrote an explicit `extends Any` (`perf-probes/prelude/distance-triage/bound-any-shadow.py`). That differs for the specification's naked-`Any` rule, which the checker tests only against a written `Any` (`OverloadingChecker.scala`'s `checkBoundAny`), so it was not reused.
