Eric Allen, David Chase, Joe Hallett, Victor Luchangco, Jan-Willem Maessen, Sukyoung Ryu, Guy L. Steele Jr. and Sam Tobin-Hochstadt; with Joao Dias, Carl Eastlund, Christine Flood, Yossi Lev, Cheryl McCosh, Janus Dam Nielsen and Dan Smith. © Sun Microsystems, Inc.

The notation of this edition. Text on a tinted ground, like this, is the 2026 revival’s: a paragraph that it added, its note on a passage that it revised, its link to an archived copy of a page that is gone. All other text is the authors’.

How this edition works A reading edition for a phone: your place, your notes, the code examples, the revival's changes.
  • All 53 chapters and appendices are here.
  • The page remembers where you stopped, in this browser, and offers to continue there.
  • The pencil at the end of a paragraph, a code example or a heading attaches a note to it. Notes lists them all, and exports them as text.
  • The examples, the displayed formulas, the tables and the grammar are set by LaTeX from the specification’s own source, as in the PDF, and shown as pictures whose text can be selected. A wide one scrolls sideways inside its frame. Code words and formulas inside a sentence are ordinary text.
  • A code example that has a source form shows it too: the Fortress that a person types. The switch above an example changes them all.
  • A box headed “Revised by the 2026 revival” marks a passage that the revival changed, on the tinted ground of the revival’s additions. A box headed “Draft note” is a note of the original authors.
  • Beside an address of the authors’ text, “archived copy” is this edition’s link to the Internet Archive.
  • The Select button beside a heading selects that section's text, for Speak.
