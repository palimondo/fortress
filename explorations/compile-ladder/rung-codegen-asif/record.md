## Revival change

**The change.** The team's code generator compiled no type assumption: `CodeGen.defaultCase` stopped at an `AsIfExpr`, 'Can't compile AsIfExpr' (`ProjectFortress/src/com/sun/fortress/compiler/codegen/CodeGen.java:1675-1677` at `ed8652dc0`), and the team's own `compiler_tests/Compiled80.fss` waited on it ("asif -- we may defer this, since it is hard and not widely used.", `:15`). The tree now compiles it as the specification reads it: "A type assumption considers both the static and the dynamic type of the value of the expression to be the specified type for the purposes of the immediately enclosing function, method, or operator invocation or field access", "a richer version of type assumption operations such as `super`" (`Specification/basic/expressions/type-annotation.tex`, "Type Assumption"). A dotted call on `e asif T` runs the body that `T` gives the method, never an override below `T`; a call whose every dispatched argument is an assumption runs the declaration at the assumed types; an assumption bound to a name, standing as a value or on a tuple is the plain value, which later calls dispatch on its own type. A dispatched call with only some arguments under an assumption is refused, 'Can't compile a dispatched call whose arguments are not all type assumptions'. Tests: `compiler_tests/AsIfCallsCompiled` (each form), `compiler_tests/XXXAsIfPartialCallCompiled` (the refusal). Walk differs from the specification, and now from the compiled path, in three places: a bound assumption keeps the assumed type for later calls, a tuple under an assumption cannot be taken apart, and an overloaded method on an assumed receiver stops (`tests/XXXAsIfBoundWalk`, `tests/XXXAsIfTupleWalk`, `tests/XXXAsIfOverloadedMethodWalk`). Reason: the specification's passage above, and the one library's own use of the assumption, which the old refusal stopped: `grep -c ' asif ' Library/*.fss` counts 21 lines in seven components, such as `(self asif Generator[\E\]).asString` (`Library/FortressLibrary.fss:1496`) and `(self asif String) CMP (other asif String)` (`Library/String.fss:397`). In compiled code, write an assumption only where a call takes it at once, and put one on every dispatched argument of an overloaded call.
