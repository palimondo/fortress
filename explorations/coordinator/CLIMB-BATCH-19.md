# Climb batch 19

## 1. For the curator

### The words this record uses

- **Walk** is the interpreter. It runs a program without static types. The **compiled path** checks a program's types with the **checker**, then makes JVM bytecode.
- **The one library** is the interpreter's library (`Library/`, `ProjectFortress/LibraryBuiltin/`). At the **switch-over** the compiled path takes it over.
- **The distance** is the number of errors the checker reports on the one library. Each error has a **site** (a file and a line). **The count** is the checker's errors on the library's `FortressLibrary` component, read by the **count stage**, which also gives the checker's time.
- A **row** is an entry of the gap ledger, cited by number. An **item** is a numbered question in PLAN's list "Pavol's answers".
- A **rung** is one fix, built by one worker in its own copy of the tree and checked by a second worker, the skeptic. A **batch** is a few rungs, merged and tested together by the **gate** and landed at once. **The gather** lands the approved rungs on `main`; a new row is written `NEW-P-1` and the like until the gather numbers it.
- **Test first.** Every fix starts with a test that shows the defect, seen failing before the edit and passing after. An **expected failure** is a test named `XXX...` that passes while the defect is there; when the fix lands it is **promoted** to a plain name.
- **Exclusion.** Two declarations of one name exclude each other when no argument can have both of their parameter types; then both may stand, whatever their return types. `f(x: ZZ32)` and `f(x: String)` exclude.
- **Existential reduction** is the type group's 2011 way to read exclusion between two declarations with static parameters: read their parameter lists together, as one tuple, not one parameter at a time. Example: `o[\T\](x: P[\T\], b: Box[\T\])` beside `o[\T\](x: Q[\T\], b: Box[\T\])`, where `P[\T\]` excludes `Q[\T\]` at one `T`. No single parameter excludes, but `Box` forces one `T` for both declarations, and at one `T` the first parameters exclude. So the pair is valid. That is your P-152.
- **The `String` sites** are three of the distance's sites in the library's string code: two calls of `asString` on a value of type `Any`, which has no such method, and one mismatch between `FlatString`'s api and its component.
