## 4. What the specification settles

The Working Draft gives numerals types of their own so that a library decides by coercions how they meet other types (`Specification-1.0-frozen/basic/expressions/literals.tex:132-148`); P-174 makes the four numbers static parameters and every number type's coercion generic over them, the library's too; P-176 makes a place one value, a JVM constant where the result is an `int`, `long`, `float` or `double`, else a `static final` filled when the class loads, with a program type's own minus. The snapshot's section 11 adds that the library's types take the same mechanism ("A separate way in the compiler for the shipped numerics is a hole in the design"). The specification's revised text states the field numerals today (F-345); rung T rewrites it.
