## Revival change

**The change.** The team's compiled checker typed every argument of a call without an expected type before it tried the call's declarations (`ProjectFortress/src/com/sun/fortress/scala_src/typechecker/impls/Functionals.scala:95-96` and `:437` at `a874948ac`, `partitionArgs` through `checkExprIfCheckable`). So a static argument of a call written as an argument took its bound when only its result mentions it, and the numeral's type when only a numeral fixes it, and the enclosing call was refused. For example, `takesBox64(mk())` with `mk[\T\](): BoxT[\T\]` and `takesBox64(b: BoxT[\ZZ64\])` gave "BoxT[\ZZ64\]->String is not applicable to an argument of type BoxT[\Object\]." Now, where the enclosing call is not accepted with its arguments so typed, the checker types each argument that is itself a call with static arguments again, once per declaration, with that declaration's parameter type as the expected type. It then invokes the most specific declaration so made applicable, and a declaration that accepts the call as written is never passed over (`Functionals.scala:739-742`, `:850-908`; tests `ProjectFortress/compiler_tests/InferCallArgumentContext`, `InferCallArgumentOverloaded`, `InferCallArgumentGeneric`, `InferCallArgumentForms`, `InferCallArgumentKeepsFit`). The inference chapter lists the context (`Specification/basic/inference.tex:148-154`, `:191-215`). A reduction's big operator, a call the desugaring writes as an argument, therefore takes the reduction's expected type where its instance at the bound does not fit it (`ProjectFortress/compiler_tests/InferBigOperatorExpectedType`). Walk is unchanged and gives the argument no expected type (`ProjectFortress/tests/XXXInferCallArgumentWalk.fss`). The reason is the specification: an identifier reference's static arguments "are statically inferred from the context of the function call" (`Specification/basic/expressions/var-ref.tex:38-40`), and the context of a call written as an argument is the parameter it is passed to. The checker's refusal above is the measured failure.
