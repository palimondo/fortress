1. **The compiled dispatch method of a trait's or an object's functional method reads each argument at its own local, wherever self stands.** Holds on the compiled path, against the compiler's prelude, for declarations without static parameters of their own (a generic functional method overloaded beside a plain one stops the code generator first, row 724). The dispatch method is an instance method of the receiver's class: self in local 0, the other arguments after it in their order without self. `OverloadSet.argumentLocal` (ProjectFortress/src/com/sun/fortress/compiler/OverloadSet.java:2357-2363), overridden in `ForTraitOrObject` (OverloadSet.java:2495-2508), gives an argument before self's place the local after its place; the type test (:1538) and the arm's call (:1876) read it.
