**Q1. What a type parameter with no bound is bounded by.** Answered (a), `Any`, by Pavol on 2026-09-27 (POSITIONS 2026-09-27, the numerics plans); the question stands below as it was put.
- What we do: the specification says a type parameter written without `extends` has the implicit bound `Object` (`Specification/basic/trait-parameters.tex:49-50`). The one library is written as if the bound were `Any`, the top type, and walk and the gate's checker count read it that way. Under `Object`, a tuple type is not a valid type argument, so every generic the library instantiates at a tuple (an index pair, a key-value pair) is ill-formed by the text. The default rewrites the sentence to `Any`. It also rewords the rule that a function whose one parameter is a bare type variable bounded by `Any` may not be overloaded (`Specification/advanced/overloading.tex:114-127`) to say what the checker checks: a written `Any` bound.
