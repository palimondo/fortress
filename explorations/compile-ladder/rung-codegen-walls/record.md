## Revival change

**The change.** The team's code generator refuses three constructs that the checker passes: an `extends` entry that gives a generic trait the static argument `Any`, whose branch in `generateTypeReference` is empty and falls to 'Only handling some static args of generic types in extends clause' (`ProjectFortress/src/com/sun/fortress/compiler/codegen/CodeGen.java:5753-5760` at the team's last commit `a874948ac`); a `try` with a `forbid` clause, on which `forTry` throws 'NYI: Forbid clauses are not yet implemented' (`:2013-2014` there); and a function declared `test`, which the modifier guard `fnDeclCompilableModifiers` leaves out, so `forFnDecl` stops with 'Don't know how to compile this kind of FnDecl.' (`:2866-2868` there). What the tree now does: it compiles all three; the `forbid` clause throws on, as a `ForbiddenException` whose `chain` is that exception, an exception of a listed type that no catch clause took, and lets one of no listed type pass on; a `test` function compiles as the function it is, and what `fortress test` runs is unchanged (`ProjectFortress/compiler_tests/ExtendsGenericAtAnyCompiled.fss`, `ForbidClauseCompiled.fss`, `TestModifierCompiled.fss`). The reason, as evidence: the specification gives the `forbid` clause's meaning, "a new ForbiddenException is created with the thrown exception as its argument and thrown", the catch clause first (`Specification/basic/expressions/try.tex:65-78`), and its equivalence to a catch clause that throws `ForbiddenException(e)` (`Specification/basic/exceptions.tex:177-210`), and the `test` modifier on a top-level function (`Specification/basic/tests.tex:36-55`); walk runs all three (`ProjectFortress/src/com/sun/fortress/interpreter/evaluator/Evaluator.java:1424-1433`, `interpreter/evaluator/CollectTests.java:51`); and the one library carries them (`Library/FortressLibrary.fss:339`, `:3728`, `:4070`; `Library/String.fss:337`), which the code generator refused while the checker passed them, measured as 'refused declarations 50' with these three kinds among 14, and 47 in 11 without them.
