6.1 What the gradient is

The loss depends on all 4,192 parameters. Change one parameter a little, and the loss changes a little. The gradient is a vector of 4,192 numbers. Its entry for a parameter is a rate: the change of the loss for each unit of change of that parameter, while the others stay as they are.

A run shows this on parameter 500. It lies in wpewpe, the table of the position embeddings, which starts at place 432 of the parameter vector: it is element [4, 4][4, 4] of that table. Its value is 0.0626. The step's gradient has -0.0926 at place 500. The run then called stepstep twice more: once with parameter 500 raised by 0.00001, once with it lowered by 0.00001.

index 500 p 0.06258901428847981 g -0.09262792010673876 loss+ 3.365966021326099 loss- 3.365967873884501 fd -0.09262792011188735

  • With the parameter raised, the loss is 3.365966021.

  • With the parameter lowered, the loss is 3.365967874.

  • The difference is -0.000001853, for a change of 0.00002 in the parameter. The rate is the first divided by the second: -0.09262792011, printed after fd.

  • The gradient's entry, printed after g, is -0.09262792011. The two agree to nine digits.

The entry is negative: raising this parameter lowers the loss. Training uses exactly this fact. It moves each parameter against the sign of its gradient entry.

The same experiment on parameter 1100, which is element [25, 12][25, 12] of lmlm, the last weight matrix, which makes the 27 scores:

index 1100 p 0.03654080103626847 g 0.031736131393025356 loss+ 3.3659672649481087 loss- 3.3659666302254805 fd 0.03173613141171927

Here the entry is positive: raising the parameter raises the loss.

The experiment needs two forward passes for one parameter. For all the parameters that is 8,384 forward passes. The backward pass gets all 4,192 entries in one pass. The field's name for it is backpropagation.

Karpathy's microGPT does not write a backward pass by hand. In his program, every number of the forward pass is an object of the class Value, with a field grad that can change. The gradient is found by going back through those objects. The flat program has no such objects. Its backward pass is written out by hand, in lines 58 to 65.

6.2 The names and the rules

57 
57(* -- backward, one line under each forward line, bottom-up -- *)
57(* -- backward, one line under each forward line, bottom-up -- *)

The comment states the plan. The backward pass takes the forward declarations in reverse order, from the loss back to the embeddings.

The names follow one pattern. For a forward value such as x4x4, the backward value is dX4dX4, with a dd in front. It has the same size. Each of its elements is a rate: the change of the loss for each unit of change of the same element of x4x4. dX4dX4 is the gradient at x4x4. For a weight matrix such as lmlm, the gradient is named gLMgLM, with a gg for gradient. The nine gg matrices are the pieces of the result.

At every forward declaration, the backward pass knows the gradient at the declared value and computes the gradient at the values that it was made from. Four rules are enough.

Rule 1, a chain: rates multiply. Suppose yy is 3 times xx, and the loss is 2 times yy. One unit more of xx gives 3 units more of yy, and that gives 6 units more of the loss. The rate at xx is the rate at yy times 3.

Rule 2, a value used twice: rates add. If xx goes into two later values, the loss changes through both, and the gradient at xx is the sum of the two parts.

Rule 3, a sum: the gradient passes through. If yy is a + ba + b, one unit more of aa is one unit more of yy. The gradient at aa is the gradient at yy, and so is the gradient at bb.

Rule 4, a product of matrices. If YY is the product A BA B, then the gradient at AA is dY BTdY B^T, and the gradient at BB is AT dYA^T dY.

The smallest case of rule 4 uses numbers from Part 2. Let AA be the one row 5, 6 and BB the one column 1, 3. Their product is one number: 5 times 1, plus 6 times 3, is 23. Let the loss be that number, so dYdY is 1.

  • Raise the 5 by one unit: the product rises by 1, the element of BB that the 5 meets. Raise the 6: the product rises by 3. So the gradient at AA is the row 1, 3. That is BTB^T.

  • Raise the 1 by one unit: the product rises by 5. Raise the 3: it rises by 6. So the gradient at BB is the column 5, 6. That is ATA^T.

A larger product is many such sums. Each element of AA enters several elements of YY, and by rule 2 its parts add. Written out, the additions give the two formulas above. The sizes are a check that you can make at every line: dY BTdY B^T has the size of AA, and AT dYA^T dY has the size of BB. The experiment of the last section is the check by a run: it agrees with the gradient that these rules give.

dLdL is the gradient at the 27 scores of every row, the matrix x4 lmTx4 lm^T that the forward pass handed to smsm, the softmax. The line uses four names of the forward pass: prpr, the probabilities; tgtg, the targets; vmvm, which holds 1.0 for a row that counts and 0.0 for the others; and nvnv, the number of rows that count, 7. 6.4 Back through lm

58 58 
58gLM = dL^T x458dX4 = dL lm
58gLM = dL^T x458dX4 = dL lm

The forward declaration is x4 lmTx4 lm^T: every row of x4x4, the result of the feed-forward block, through the last weight matrix, lmlm. In rule 4, AA is x4x4, BB is lmTlm^T, and dYdY is dLdL.

  • The gradient at AA is dY BTdY B^T. The transpose of lmTlm^T is lmlm. So dX4 = dL lmdX4 = dL lm.

  • The gradient at BB is AT dYA^T dY, which is x4T dLx4^T dL. That is the gradient at lmTlm^T. The gradient at lmlm itself is its transpose, and the transpose of x4T dLx4^T dL is dLT x4dL^T x4.

Seven of the nine weight matrices enter the forward pass in this form, and their gg lines all have this shape: the transposed gradient of the result, times the input. A run printed the sizes:

sizes dL (16,27) gLM (27,16) dX4 (16,16)

gLMgLM has the size of lmlm, and dX4dX4 the size of x4x4.

The _b stands for backward. rmsn_brmsn_b takes dydy, the gradient at the result of rmsnrmsn, and xx, the vector that rmsnrmsn was applied to. It returns the gradient at xx.

  • Line 26 computes again what rmsnrmsn computed: the root rr of the mean square plus ϵepsilonε, which is 0.00001, and the result yy.

  • Line 27 is the gradient. It has two parts, because a change of one element of xx does two things.

  • First, the element's own result changes: yy is x / rx / r, so one unit more of an element is 1 / r1 / r more of its result. This part is dy / rdy / r.

  • Second, the root rr changes a little, and every element of yy changes with it. This part is the term that line 27 subtracts: yy, times the number (y · dy) / |y|(y DOT dy) / |y|(y · dy) / |y|, divided by rr.

In line 27, y (…)y (...) is a vector beside a number: juxtaposition multiplies every element.

  • dy, x, r and y are the names of the code.

  • y · dy is y · dyy DOT dyy · dy, and n is |y||y|.
