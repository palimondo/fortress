## The APL side quest, where it stands

Goal as Pavol set it: convert APL syntax into efficient Fortress code over Fortress's native arrays, not an interpreter of APL in Fortress. The design and the ladder are in `explorations/apl/README.md`; the base is `explorations/apl/base/` (`AplCore.fss/.fsi` the library, `AplSyntax.fsi` the grammar). Rungs 1 to 6 are done and green, one directory each with `DESIGN.md` (rungs 3 to 6, mine), `REPORT.md`, `PROBES.md`, probes with `.out`, and `RungN.fss` checked against the book's printed output in `explorations/apl/goldens/ch1..ch6`. Rung 7 (tacit) is skipped: the programs have one tacit line, rewritten. Rung 8 (nested arrays) is not built; strands of arrays became Fortress tuples in rung 5, which covers what the programs use.

Mechanisms established, all in `explorations/apl/gaps.md` (85 rows, not yet merged into the main ledger): glyphs as host operators where the operator table allows; templates expand to host code; rank in the type with overload families over `RR64`/`Vector`/`Matrix`/`Array3`; rank read off the source text for `⍴ ⌷ ↑ ↓ ⍉`; a glyph handed to an operator is a zero-parameter host lambda over a frame stack (`aplCall`, `aplAlpha()`, `aplOmega()`, `aplSelf()`), which is the only form that survives nested dfns because the interpreter refuses every re-declaration of a name (rung-4 probes u01 to u03); guards as `if … then … else rest end`; `⍤1 ⍤2 ⍤0 1` over row and plane views with the result rank chosen by overloading on the first cell's result; `+.×` is the shipped `DOT`; outer products direct for the common glyphs; `¨` over simple arrays and over tuples; destructuring `a b c ← e` as a lambda over a tuple; `\ ⍀ ⍣` and general `f/`. APL names are a closed set in the grammar, one line per name, three sets (arrays, functions, tuple members); a word of two or more capitals cannot be a name.

What the microGPT programs still need from the ladder and that no chapter provides: rank 4 for batch by head by position by head-dim with `0 2 1 3⍉`, matrix views over slices of a flat parameter vector, `⊃,/,¨` to flatten a tuple of matrices, and the `∘←` state updates of Adam. Decision taken with Pavol: this is one program-specific design, written after Run C2 and C3 land, against their Fortress, which is what the APL expansion should produce. The closing step of the side quest is the flat-style microGPT written in the APL sub-language and checked against the same goldens. After that, the 85 APL rows go into the main ledger through the merge worker.

Reference programs under `explorations/apl/reference/`: `nydhal-dyalog/` (Nydhal Selmi's MIT Dyalog port, rank 3, per document), `dzaima/` (a dzaima/APL rewrite, verified), `hsu-flat/` (the data designed after Hsu: `microgpt_concise.dyalog`, 25 lines, unverified in Dyalog; `microgpt_flat.apl` verified in dzaima; `microgpt_flat.py` verified numpy; `HANDOVER-HSU.md` with the tactics table).
