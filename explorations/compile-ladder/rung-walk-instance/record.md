## FACTS.md entry (section "Landed semantics")

- **Under walk, a type parameter that nothing at a call fixes takes its declared bound, and a lone one with no narrowest candidate its bound** (`compile-ladder/rung-walk-instance/REPORT.md`).
  - This holds where walk instantiates the declaration a call runs (`EvaluatorBase.inferAndInstantiateGenericFunction`); the bound is `Any` if none is written.
  - A join of several minimal common supertypes takes the bound too.
  - A typecase that matches nothing throws `MatchFailure`, and generic functional methods run.
  - Still `BottomType`: an F-bounded parameter, a big operator's static parameters, a parameter declared with several bounds walk cannot meet (row 591), and a parameter that only an untyped function expression's result fixes (row 587, an expected failure).
  - Two exceptions to the bound: a parameter that only another fixed parameter's bound mentions takes the arguments' type (row 592, decision D3); and a lone parameter whose bound mentions a static parameter, or with several bounds walk cannot meet, takes the arguments' narrowest named common supertype as before, the second failing where there is none (row 591).
  - Choosing a declaration is unchanged (row 589).
  - Gated by `tests/InferUnfixedBoundWalk.fss`, `InferLoneUnboundedWalk.fss`, `InferTwoCommonParentsWalk.fss`, `TypecaseNoMatchWalk.fss`, `GenericFunctionalMethodWalk.fss` and `GenericTraitGenericFunctionalMethodWalk.fss`; the departures by `XXXInferSeveralBoundsWalk.fss`, `XXXInferThroughBoundWalk.fss` and `XXXInferUntypedLambdaResultWalk.fss`.

Correction for the gather in the same commit: the entry "Under `walk`, a generic call's static arguments are inferred with coercion ..." says that a lone parameter's candidates include the arguments' supertypes and that "a `ZZ64` with an `RR64` [gives] `Number`". Since this rung, that holds only for a parameter whose bound mentions a static parameter, or that is declared with several bounds walk cannot meet. Otherwise a `ZZ64` with an `RR64` gives the declared bound: `Number` where written, `Any` unbounded.
